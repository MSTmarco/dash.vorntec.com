03 · The digital twin

Where a process twin fits

Many plants already have a steady-state process model, calibrated on real data. This demo does not run one. Where the twin would give the expected value, we use a simple physics curve fitted on the healthy stretch of each run. The twin would replace that curve. The detector stays the same.

Use 1 · Residualsmeasured − expected

Real inputs go into the model, and the model gives the expected value: CO₂ at the amine outlet, reboiler duty, cold box ΔP. The difference with the measured value is a feature for the detector.

Use 2 · Physical rangeswhat is possible

The model says which combinations of values can happen. A reading outside that envelope is an instrument problem or a real upset. This matches the physics layer we already run.

Use 3 · Simulated faultsfaults on demand

Lower the amine strength in the model and see which signal moves first. Real failures are rare, so this is how we get enough cases to set a threshold.

Limitssteady state

A steady-state model does not handle starts and trips well. It is slow and needs a licence, so we run it over many operating points and fit a fast surrogate. Its calibration ages, for example with the O₂ catalyst.
